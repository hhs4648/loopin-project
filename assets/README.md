# assets

Figma export / 사진 / SVG를 **여기에만** 넣으세요.

## 규칙

- 에셋은 **`assets/` 폴더에만** 둡니다.
- `public/`, `figma/` 등 **다른 곳에 복사하지 않습니다.**
- AI는 **파일 내용 수정 X**, **이름만** 영문 kebab-case로 변경 (rename).
- 하위 폴더 나누기는 **사용자가 지시할 때만**.
